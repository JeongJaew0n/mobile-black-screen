# glossary

이 프로젝트 안에서만 통하는 도메인 용어를 정의한다. **새로 합류한 사람(과 AI)이
코드를 읽기 전에 먼저 읽는 문서**다.

용어가 흔들리면 코드도 흔들린다. 같은 것을 어디서는 `order`, 어디서는 `purchase`,
어디서는 `transaction` 이라 부르기 시작하면 그때부터 대화도 코드도 어긋난다.

## 무엇을 적나

**일반적인 뜻과 이 프로젝트에서의 뜻이 다른 것**만 적는다.

| 적는다 | 적지 않는다 |
|---|---|
| 이 프로젝트에서만 특별한 뜻인 말 | 일반 기술 용어 (`캐시`, `마이그레이션`) |
| 업계 용어인데 우리가 좁게/넓게 쓰는 말 | 코드를 보면 바로 아는 것 |
| 비슷한데 구분해서 써야 하는 두 말 | 한 번 쓰고 마는 말 |
| 팀이 합의한 약어 | |

판단 기준 — **"이 말을 처음 듣는 사람이 코드에서 만나면 헷갈릴까?"**

## 형식

용어 표를 이 파일에 유지한다. 설명이 길어지는 용어만 따로 파일로 뺀다.

| 용어 | 정의 | 비고 |
|---|---|---|
| Screen Off | 화면을 검게 덮어 꺼진 것처럼 보이게 하는 이 앱의 핵심 동작. **사용자에게 보이는 이름** | 화면을 실제로 끄지 않는다 — Android 에 그 API 가 없고, 끄면 시계도 못 띄운다 |
| 차폐 (cover) | Screen Off 와 **같은 것**의 코드·문서 이름. `ScreenCoverService`, `coverView`, "차폐 창" | UI 문자열에는 쓰지 않는다 |
| 차폐 창 | 화면을 덮는 창 자체. 창 종류가 모드를 결정한다 | 버블 창과 다름 — 버블 창은 덮지 않고 떠 있다 |
| FULL | 접근성 오버레이(`TYPE_ACCESSIBILITY_OVERLAY`)로 상태바·내비바까지 덮는 모드. **기본이자 유일하게 제공되는 모드** | 쓰던 앱이 그대로 남는다 |
| Overlay | `TYPE_APPLICATION_OVERLAY` 창으로 덮는 모드. 시스템 바는 못 덮는다 | `Mode.available = false` 로 미제공. 코드는 남음 |
| Blackout | 풀스크린 Activity 로 덮는 모드. 권한 0개지만 쓰던 앱이 뒤로 밀린다 | 미제공. 한때 잘못 기본값이었다 (`docs/plans/blackout-overlay-modes/`) |
| 버블 (bubble) | 다른 앱 위에 떠 있는 작은 원형 버튼. 탭 = Screen Off, 끌기 = 이동, 꾹 누르기 = 겨냥 | `ScreenCoverService` 가 차폐 창과 함께 소유한다. 서비스를 나누지 않는다 |
| 겨냥 (aim) | 버블을 꾹 누른 뒤 손가락을 위/아래로 옮겨 동작을 고르는 제스처. 위 = 앱 열기, 아래 = 버블 닫기 | `BubbleAim`, `AimTargets`. 순 변위 44dp 로 판정 |
| 닫기 vs 숨기기 | **닫기**(겨냥 아래·알림 액션)는 창만 지우는 일시적 동작 — 앱을 열면 돌아온다. **숨기기**는 설정 스위치로, 켜 두면 앱을 열어도 안 뜬다 | 둘 다 `화면 위 버블 표시` 옵션은 건드리지 않는다 |
| 해제 (unlock) | 차폐를 푸는 것. 단일 탭이 아니다 — 주머니에서 풀리기 때문 | 제공: 꾹 눌러 해제 / 더블 탭 / 3회 연속 탭(기본) / 지문(API 28+). 밀기 계열 둘은 코드만 남고 미제공 |
| 밀어서 잠금 해제 | 옛 아이폰식. 하단 트랙의 손잡이를 오른쪽으로 끝까지 끌면 풀린다 | **위로 밀어 올리기**(`SWIPE`, 화면이 벗겨지며 올라감)와 다름. **둘 다 미제공** (`available = false`) |
| 번인 시프트 | 60초마다 글자 위치를 8dp×28dp 타원 궤도로 옮기는 것. 끌 수 없다 | 애니메이션 없이 즉시 이동 |
| 표시 내용 (content) | 차폐 화면에 뜨는 것 — 시계·날짜·배터리·문장. 기본은 **전부 꺼짐 = 완전한 검정** | `hasContent` 가 참일 때만 밝기가 0 위로 올라간다 |
| 스타일 (`ClockStyle`/`DateStyle`) | 시계·날짜의 **저장값**. 패턴 문자열이 아니라 ICU 스켈레톤 | 패턴은 렌더 시점에 로케일이 정한다 (`architecture.md` §5.1) |
| 눈금 (tick) | 전력 측정에서 쿨롱 카운터가 뛰는 단위, 8750 µAh | 눈금이 10개 안 쌓이면 그 측정은 못 믿는다 |
| 미디어 소리 끄기 | 차폐를 켤 때 미디어 음량만 0 으로 내리는 선택 항목. 3택: 끔 / 일시 음소거 / 볼륨 0 | **미디어(`STREAM_MUSIC`)만**. 알림·통화·벨은 안 건드린다. 블루투스로 듣는 중이면 건너뛴다 |
| 일시 음소거 vs 볼륨 0 | **일시 음소거**는 차폐 동안만 0 이고 해제하면 원래 음량으로 돌아온다. **볼륨 0** 은 진짜로 내려 해제해도 0 이다 | 차이는 "되돌아오는가" 하나뿐이라 한 자리에서 고른다 (`architecture.md` §4.10) |
| 재생 바 (`MediaBar`) | 재생 중인 음악·동영상의 제목·진행을 차폐 하단에 보이는 것. 표시 전용 | 알림 접근 권한 필요. `NowPlaying` 은 시스템이 준 스냅샷이고 위치는 계산한다 |

## 규칙

- **코드의 이름과 일치시킨다.** 용어집에 `Draft` 라고 적었으면 코드에서도 `Draft` 다.
  적어놓고 코드에서 다르게 부르면 용어집이 거짓말이 된다.
- **이름을 바꾸면 용어집부터 고친다.** 코드만 바꾸고 두면 다음 사람이 낡은 정의를 믿는다.
- **혼동하기 쉬운 짝은 함께 적는다.** `Draft` 와 `Temp` 처럼 구분이 중요한 것은
  비고에 "무엇과 다른지" 를 쓴다. 정의만 있으면 경계가 안 보인다.
