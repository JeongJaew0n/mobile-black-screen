# 전력 측정 뒤 모든 앱 전환이 느려졌다

## 증상
"모든 앱이 켜지고 닫힐 때 애니메이션이 100배 느리다". 앱 실행 시간(283ms)·프레임 시간(5ms)·
CPU 클럭·발열은 전부 정상이었다.

## 원인
측정으로 배터리를 29% 까지 떨어뜨려 삼성 **절전 모드가 자동으로 켜졌고**(`Sticky=true` 라 충전
후에도 유지), 절전 모드가 주사율을 60Hz 로 강제했다. 절전을 끈 뒤에도 주사율은 60Hz 에
남았다 — Device Care 의 복원값이 -1(백업 없음)이었다.

## 해결
설정 → 디스플레이 → 모션 부드럽게 → 적응(120Hz). `dumpsys display` 의
`primary=physical: (10.0 120.0)` 으로 확인.

## 재발 방지
전력 측정 절차 끝에 "절전 모드와 주사율 범위를 확인해 원복" 을 넣는다.
`dumpsys display | grep primary=physical`, `settings get global low_power`.
