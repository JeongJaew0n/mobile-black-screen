# 새 UI 를 넣었는데 화면에 안 뜬다 — 빌드는 통과

## 증상
`SlideToUnlockLayer` 를 만들고 커밋·푸시까지 갔는데 실기기에서 트랙이 없다.
설정에서 그 제스처를 고르면 화면을 풀 방법이 없다.

## 원인
`BlackScreenRoot` 에서 그 레이어를 **부르는 분기를 빠뜨렸다.** 앞선 편집 배치가 중간에
실패해 일부만 재실행됐다. 미사용 public Composable 은 컴파일도 lint 도 그대로 통과한다.

## 해결
분기 추가. 실기기에서 트랙이 뜨는 것을 확인.

## 재발 방지
UI 를 추가했으면 "빌드 성공" 이 아니라 **화면에 떴는지**로 확인한다.
