# 항목 하나를 바꾸면 다른 설정이 전부 기본값으로 돌아간다

## 증상
앱을 막 연 직후 설정 하나를 바꾸면 나머지(해제 제스처, 시계 등)가 기본값으로 덮인다.
"3회 연속 탭 설정해놨는데 앱 껏다켤때마다 초기화" 로 보고됐다.

## 원인
`MainActivity` 가 화면이 들고 있는 `Settings` **스냅샷을 통째로** 저장했다. DataStore 가
아직 값을 방출하지 않은 시점(`initialValue = Settings()`)에는 스냅샷이 전부 기본값이라,
항목 하나를 바꾸는 순간 기본값 덩어리가 저장됐다.

## 해결
`SettingsScreen.onChange` 가 스냅샷 대신 **변환 함수** `(Settings) -> Settings` 를 받고,
호출부가 `repository.update(transform)` 으로 저장된 값을 읽어 변환한다.

## 재발 방지
설정 저장 경로에 `copy(...)` 스냅샷을 넘기는 코드가 다시 생기면 이 문서를 가리킨다.
