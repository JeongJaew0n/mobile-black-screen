# 30분 전력 측정이 무효 — 폰이 잠겨 있어 탭이 잠금화면에 떨어졌다

## 증상
30분 측정 결과에 접근성 창 수가 0. Screen Off 가 시작된 적이 없었다.

## 원인
측정 시작 시 폰이 잠겨 있었다. 버블 탭이 잠금화면에 떨어져 차폐가 뜨지 않았는데,
스크립트는 상태를 로그만 하고 계속 진행했다.

## 해결
조건 시작 시 접근성 창 수·밝기 오버라이드·`isKeyguardShowing=false` 를 검증하고 어긋나면
**즉시 중단**하도록 바꿨다. 이후 4조건 × 30분 실측 성공 (`docs/power-measurement.md`).

## 재발 방지
검증 게이트는 로그가 아니라 중단이어야 한다. 실기기 테스트 전에 `isKeyguardShowing` 을 본다.
