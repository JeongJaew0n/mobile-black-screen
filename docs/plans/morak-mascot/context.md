# 왜 시작했는가

> 사후에 고쳐 쓰지 않는다. 2026-10-30 시점의 판단 기록이다.

## 원 요청

다른 세션(REA)이 마스코트 "모락" 을 이 앱에 넣자고 전해 왔다. 앱 코드를 건드리기 전에 시안부터 만들었다
(artifact "모락 × 검은 화면", 2026-10-30). 시안을 본 사용자의 답:

> 뭐야 모락 적용안됐네? 모락 적용해. 기획 맘에 든다.

모락은 김이 나는 머그잔 캐릭터다. 결점이 "금방 식는다" 라서, 화면을 식히는(끄는) 이 앱의 얼굴로 읽힌다.

## 결정

시안의 "정할 것" 셋은 "기획 맘에 든다" 를 시안 그대로 승인한 것으로 읽었다.

- **색: 수묵 모락.** 원본 선 `#2b2326` 은 밝은 종이를 전제로 한 색이라 앱 배경 `#161616` 에서 외곽선이 사라진다.
  선을 paper 로, 면을 먹(wash)으로 뒤집으면 **기존 ref 팔레트만으로** 그려진다. 새 원시색 0.
- **자리: ①~⑥ 전부.**
  ① 앱 제목 옆(기본 표정) ② 권한 안내 카드(식은 표정) ③ 권한을 켜고 돌아왔을 때 2초(따끈한 표정, 문구 하나)
  ④ 버블 기호에 '머그' 추가(얼굴 없음, 기본값은 그대로 막대) ⑤ 타일·알림 아이콘을 김 한 가닥으로
  ⑥ 런처 아이콘을 수묵 모락으로. ⑥ 은 시안에서 "선택 사항" 이었지만 "모락 적용해" 의 가장 눈에 띄는 자리라 넣었다.
- **넣지 않는 곳: 차폐 화면·해제 안내·지문 프롬프트·미리보기.** 무엇이든 그리면 패널 밝기가 0 에서 올라간다.
  미리보기는 실제 차폐와 같은 그림이어야 한다.
- **그림은 생성한다.** 원본의 흔들리는 선은 SVG `feTurbulence` 필터인데 VectorDrawable 에는 필터도 패턴 채우기도 없다.
  `design/mascot/build.py` 가 경로를 노이즈로 밀어 굽고(시드 고정 → 매번 같은 선), 빗금은 `<clip-path>` 안의 선으로,
  리소(색면 어긋남)는 `translateX/Y` 그룹으로 만든다. `design/tokens/build.py` 와 같은 방식(`--check`)이다.
- **색은 토큰을 따른다.** `comp.mascot.*` 가 기존 ref 를 가리키고, 그림 XML 은 `@color/comp_mascot_*` 를 쓴다.
  팔레트를 바꾸면 모락도 따라 바뀐다.

## 기각한 대안

- **Compose Canvas 로 직접 그리기** — 런처·타일·알림 아이콘은 XML 이어야 해서 그림 원본이 둘로 갈린다.
- **PNG 로 넣기** — 토큰을 따르지 못하고 밀도별 파일이 생긴다.
- **원색 모락** — 어두운 앱에서 외곽선이 묻히고, 민트·코랄이 수묵 팔레트에 없는 원시색이라 토큰이 늘어난다.
