## 코드 리뷰 (2026-11-03)

실기기(S23+ / Android 16, 무선 adb)에서 **수정 전·후를 둘 다 재현**해 판정했다.

- [x] '준비됐어요' 가 남는다 — 2초 대기 중 권한이 다시 꺼지면 코루틴이 취소돼 끄는 줄이 안 돈다. 수정 전 빌드에서
  권한을 끈 3초·6초 뒤에도 남는 것을 재현(식은 모락 카드와 따끈한 모락이 동시에) → `finally` (a4da5a0)
- [x] 화면이 다시 만들어지면 안 뜬다 — `remember` 라 "권한 없이 떠났다" 를 잊는다. 글자 크기를 바꿔 relaunch
  (`wm_relaunch_resume_activity`) 시켜 수정 전 안 뜸 · 수정 후 뜸 → `rememberSaveable` (a4da5a0)
- [x] 권한 카드 버튼 — 영어·일본어에서 둘째 버튼이 짓눌려 글자가 세로로 섰다. 한국어(글자 1.1)는 1.5dp 남기고 들어갔다.
  리뷰의 "한국어도 넘친다" 는 틀렸다 → `FlowRow` (0dd3a3d)
- [x] 스크린리더 — liveRegion 은 새로 나타난 노드에 이벤트를 안 보낸다(Compose 1.12 소스) → `paneTitle`.
  `PANE_APPEARED` Text [준비됐어요] 를 시험 빌드 로그로 확인. TalkBack 소리는 듣지 않았다 (0dd3a3d)
- [x] 테스트 중 발견 — 글자 200% + 권한 카드에서 미리보기가 탭·시작 버튼을 덮었다 → `weight` 영역 + 받은 높이 지키기 (f025bfe)
- [x] 테스트 중 발견 — uiautomator 가 붙는 동안 접근성 서비스가 꺼진다. 10-30 의 "덤프에 남은 카드" 의 진짜 원인. 문서만 고침
- 관찰만 — 재설치 뒤 재생 바 부제에서 앱 이름(넷플릭스)이 빠졌다. 넷플릭스는 `<queries>` 에 걸리는 선언이 없다.
  재설치 전에 보였던 이유는 확인하지 않았다
