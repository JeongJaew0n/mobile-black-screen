# 왜 시작했는가

> 사후에 고쳐 쓰지 않는다. 2026-10-01.

## 원 요청
> 전부 구현해. 연결해놨어. 구현및 테스트 다하면 화면꺼라.
> 설정에 자동으로 끄기 기능생겼던데 기본값은 끄기로 해놔라.

"전부" 는 `docs/ui-research.md` 의 1~7. 자동 끄기 기본값은 코드에서 이미 0(사용 안 함)이고 기기 저장값도 0 이었다
— 지난 테스트의 1분은 그 사이 풀려 있었다. 바꿀 것 없음을 확인했다.

## 결정
- 1(미리보기)·4(묶음 카드)·5(하단 시작 버튼)는 설정 화면의 짜임을 함께 바꾸므로 한 번에 다시 쓴다.
- 미리보기 접힘은 높이만 줄이지 않고 **내용을 통째로 축소**한다. 높이만 줄이면 시계(64sp)가 잘려 고장처럼 보인다.
- 칩은 안정 API `FilterChip` + `FlowRow`. M3 Expressive 버튼 그룹은 실험 API 라 뺐다(연구 §3).
- 48dp 는 토큰 `sys.touchTarget.min` 을 고친다. 44 는 iOS 값이었다. 재생 버튼도 함께 커진다.
- 설정 탭의 라디오 중 소리(설명 있음)·해제(슬라이더가 붙음)는 라디오로 둔다.
