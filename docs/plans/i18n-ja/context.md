> 사후에 고쳐 쓰지 않는다. 2026-09-28 시점의 판단 기록이다.

## 원 요청

> 다국어 설계하고 구현해. 테스트는 나중에.
> (이어서) 영어, 한국어, 일본어 정도.

## 출발점

다국어 구조는 1차 작업(`docs/plans/i18n/`)에서 이미 끝났다 — 기본 로케일 영어(`values/`), 한국어
(`values-ko/`), 시계·날짜 패턴은 ICU 가 로케일에서 만들고, 숫자는 서식 문자열로 리소스에 넘긴다.
1차 결정 기록에 "ja 문자열은 요청 시 파일 하나로 추가" 라고 적어 두었다. 이번이 그 요청이다.

그래서 이번 작업의 몸통은 **`values-ja/strings.xml` 하나**다. 코드 변경은 없어야 정상이다 —
있다면 1차 작업이 로케일 의존을 덜 걷어낸 것이다.

## 결정

- **"Screen Off" 는 번역하지 않는다.** 한국어에서도 그대로 쓰는 이 앱의 기능 이름이다(`CLAUDE.md` 용어 절).
- **OS 설정 항목 이름은 일본어 Android 표기를 그대로.** 직역하면 사용자가 그 항목을 못 찾는다.
  AOSP 일본어 표기를 썼다 — *他のアプリの上に重ねて表示*, *ユーザー補助*, *通知へのアクセス*.
  **삼성 One UI 일본어 표기와 같은지는 확인하지 못했다**(기기 언어를 바꿔야 한다). checklist 에 남긴다.
- **앱 이름 `黒い画面`.** 한국어 `검은 화면` 과 같은 결의 직역. `ブラックスクリーン` 은 외래어라 기능이
  아니라 제품명처럼 읽힌다.
- **문체는 です・ます.** 설정 화면 설명문의 일본 앱 관례.
- **알림 문구 `overlay_running_desc` 를 세 언어 모두 고친다.** "길게 눌러 해제" 라고 되어 있었는데 기본
  해제는 3회 탭이고 사용자가 바꿀 수 있다. 틀린 문장을 옮기는 건 의미가 없어, 특정 제스처를 말하지
  않는 문장으로 바꿨다.
