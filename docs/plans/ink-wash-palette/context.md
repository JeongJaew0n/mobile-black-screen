# 왜 시작했는가

> 사후에 고쳐 쓰지 않는다. 2026-09-28 시점의 판단 기록이다.

## 원 요청

> 수묵화로 가자. 전체 디자인 토큰 제작먼저하자. 앱에 적용할 용도임.

직전에 Figma 색상 조합 100선에서 네 후보(수묵화·고딕 누아르·달빛 아래·한밤의 모래사장)를
추렸고, 사용자가 수묵화(Ink wash — `#4A4A4A` `#CBCBCB` `#FFFFE3` `#6D8196`)를 골랐다.

## 결정

- **원색 넷만으로는 앱이 안 칠해진다.** 설정 화면은 Material 3 가 표면 4~5단계와 강조의 짙은/옅은
  톤을 요구한다. 원색 사이와 양 끝을 메워 `wash200…950`, `slate200…900` 스케일로 펼쳤다.
  원색은 `$description` 에 "원색" 으로 표시해 어느 것이 피그마에서 왔는지 남겼다.
- **"전체" = 차폐·버블 + 설정 화면.** `sys.color` 에 Material 3 색 역할 이름(surface, primary,
  outline…)을 그대로 더했다. 이름이 표준이라 다른 제품에서도 읽히고 `colorScheme` 에 그대로 꽂힌다.
- **바탕은 `#000000` 그대로.** AMOLED 에서 발광하지 않는 것이 이 앱의 이유다.
- **글자는 `#FFFFE3`(paper).** 흰색 대비 20.7:1 — "글자는 거의 흰색" 규칙 안이다. 푸른 기만 빠진다.
- **강조는 원색 `#6D8196` 이 아니라 한 단계 짙은 `#4C5D70`.** 원색 위 paper 글자가 4.0:1 로
  기준 4.5 에 못 미쳤다(겨냥 칩 라벨 15sp). 짙은 톤은 6.7:1.
- **빨강은 이전 값 유지.** 수묵화에 경고색이 없다. '버블 닫기' 가 '열기' 와 헷갈리면 안 된다.

## 범위 밖

`MainActivity` 의 `MaterialTheme(colorScheme = darkColorScheme())` 를 이 토큰으로 바꾸는 것은
하지 않았다 — 요청이 "토큰 제작 먼저" 였다. 차폐·버블은 이미 `Sys.Color` 를 참조하므로 **이 커밋으로
바로 바뀐다.** 설정 화면만 다음 단계에서 바뀐다.
