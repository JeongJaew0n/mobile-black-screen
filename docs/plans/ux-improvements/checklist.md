### 테스트 중 내 실수 (기록)
- 스위치를 끈 뒤 목록이 접히는데 좌표를 다시 잡지 않아 다른 스위치를 껐다 → 저장값을 해독해 원복, 도우미를 "누를 때마다 다시 읽기" 로
- uiautomator 덤프에 남은 노드를 보고 "카드가 안 사라진다" 로 오진 → 스크린샷 픽셀로 반증
- 설치 출처를 되돌리려다 `uninstall -k` 를 실행 — 제거는 실패했고 데이터 그대로. 일반 `install -r` 로 복구(출처 `null`)
