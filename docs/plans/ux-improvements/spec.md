# UX 개선 — 무엇을 만드는가

## A. 해제 방법을 보이게

### A1. 시작 버튼 아래 한 줄 (설정 화면)
지금 고른 해제 방법 + 켜져 있는 부수 효과를 한 줄로.

| 상태 | 문구 (ko) |
|---|---|
| 3회 탭 | 3번 탭하면 풀립니다 |
| 더블 탭 | 2번 탭하면 풀립니다 |
| 꾹 누르기 | 꾹 누르면 풀립니다 |
| 지문 | 지문으로 풀립니다 |
| + `볼륨 0` | · 미디어 볼륨을 0 으로 내립니다 |
| + `일시 음소거` | · 미디어는 음소거됩니다 |
| + 타이머 | · 30분 뒤 화면이 꺼집니다 |

### A2. 차폐 중 첫 동작에 안내 (차폐 창)
- 3회·2회 탭: 첫 탭(연속 탭 창 안에서 해제 전까지 매 탭)에 "N번 더 탭하면 풀립니다".
- 꾹 누르기: 짧게 탭하고 떼면 "꾹 누르면 풀립니다".
- 지문: 안내 없음 — 탭이 곧 프롬프트이거나 버튼이 보인다.
- 5초 뒤 사라진다. 떠 있는 동안 밝기 `CONTENT_BRIGHTNESS`.
- 자리: 진행 링과 같은 높이(중앙 아래 28%) — 시계 블록·재생 바와 겹치지 않는다.

## B. 자동 종료 타이머
- 설정: 끔(기본) / 15분 / 30분 / 1시간 / 2시간. `Settings.autoOffMinutes: Int = 0`.
- 차폐를 켤 때 시작, 풀 때 취소. 끝나면 `hideCover()` → `GLOBAL_ACTION_LOCK_SCREEN`.
- 미디어는 멈추지 않는다. 볼륨 복원은 `hideCover()` 가 한다(일시 음소거면 원래 음량으로 돌아온 뒤 잠긴다).
- API 27 이하는 잠금 동작이 없어 차폐만 푼다.

## C. 권한 안내
- **C1. 제한된 설정 안내** — 접근성 카드·알림 접근 카드에, 사이드로딩 + API 33+ 일 때만 한 문단 +
  [앱 정보 열기] (`ACTION_APPLICATION_DETAILS_SETTINGS`).
  "'제한된 설정' 경고가 뜨면 닫고, 앱 정보 → ⋮ → '제한된 설정 허용' 을 누른 뒤 다시 켜 주세요."
- **C2. 설정이 열리는 이유 알리기** — 타일·버블에서 접근성이 꺼져 설정을 열 때 토스트
  "Screen Off 를 쓰려면 접근성 권한을 켜 주세요".
